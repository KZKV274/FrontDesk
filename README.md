# FrontDesk

PWA для ресепшена отеля: шахматка 53 номеров (3–10 этаж), передача смены с готовым отчётом, напоминания (будильники, такси, трансферы), контакты и шпаргалка.

Данные хранятся только на телефоне (localStorage + IndexedDB). Регулярно сохраняйте резервную копию: «Ещё» → «Резервная копия».
Личные данные гостей (ФИО, паспорта, телефоны) в приложение не записываются.
